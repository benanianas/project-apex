# Assets and dependencies

- APEX wordmark/icon SVG, generated PNG icons and exercise movement schematics: original vector artwork created for this project. No hotlinked or downloaded exercise photography.
- Exercise guide text: original concise instructions tied to the supplied APEX program. SVGs are simplified instructional schematics; all guides work without internet.
- UI icons: Lucide (ISC license); distributed through the installed `lucide-react` package.
- Fonts: device system fonts; no network font requests.
- Video resources: clearly labeled YouTube search URLs assembled from exercise names. No direct demonstration URL is represented as verified, and no video is preloaded or cached.
- Library licenses and exact versions are in the lockfile and each installed package's license metadata. Application assets contain no third-party analytics or remote media.
