# Physical iPhone / Safari QA

Automated tests use the Playwright iPhone 17 Pro profile (402 × 681 CSS-pixel Safari viewport) with Chromium and WebKit. An additional 402 × 874 full-screen check injects representative safe-area insets; it is not real Home Screen emulation. These are not physical-device tests. Before relying on a new installation:

1. Open the HTTPS deployment in Safari. Confirm Boxing Readiness, seven numbered days and 19/22/22 strength sets including optional work (5/5/6 mandatory movements). Add to Home Screen and launch the icon. Check icon, safe areas and standalone appearance.
2. Wait for Offline ready. Enable Airplane Mode, fully close/reopen the installed app, and confirm Today, an unvisited exercise guide and Progress load.
3. Start a workout. Tap an exercise name and verify logging appears first, progress next, then the Exercise info button. Change a set and return with Open workout; both views must share the same saved values. Enter dumbbell weights, reps and RIR with the numeric keyboard. Confirm fields and finish actions stay reachable, only the native keyboard supplies Next/Done controls, and a bottom sheet can be closed by its close button or a downward drag on its handle. Mark a set done, background/terminate/reopen, and verify the draft and values.
4. Start the rest timer, lock the phone, wait, unlock. Remaining time should follow elapsed wall time, not a paused interval counter. Pause/reset/adjust.
5. Log cardio and rope offline. Close a partly filled activity form and reopen it. Complete/save a session, inspect charts and edit its history.
6. Export a JSON backup to Files; verify its actual filename/content. Try Share Sheet export to a chosen destination. Download/export success does not itself verify that the destination kept the file.
7. Import the saved file, inspect counts, and merge twice (no duplicates). With a separate copy safely retained, test Replace after typing REPLACE. Verify custom programs, logs, preferences, and unfinished drafts return.
8. Reconnect. Verify no records disappear. With an update available and a workout active, verify there is no automatic reload. Save/leave the logger, then apply the update in Settings and confirm history survives.
9. Test text enlargement, VoiceOver essential controls, landscape, focus, safe-area padding, reduced motion and charts' value tables.
10. If moving between Safari, installed app, profiles or hosting origins, export from the source context and restore in the destination. Never assume automatic transfer. Do not test storage clearing without a verified external backup.

iOS can evict website storage despite a successful installation. Persistent storage requests, background execution, Share Sheet capabilities and installation menus vary by browser/OS. No push/background notification guarantee is made.

For Boxing Readiness, also check the previous-set reference directly above entry (including lb/hand and unknown RIR), the skip-reason sheet, optional omissions when finishing, and changing priorities without changing a saved session. Weeks 1–2 must keep Day 6 aerobic; interval/jump controls become available from week 3 and still require a manual choice. Verify actual interval and rope rounds survive reload/export/import. Day 7 optional mobility should never create a required-training target.
